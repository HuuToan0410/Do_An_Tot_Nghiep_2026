# Used Car Thesis Backend

## Mô tả
Hệ thống quản lý và mua bán xe cũ.

## Công nghệ sử dụng
- Python
- Django / FastAPI (ghi đúng framework bạn dùng)
- PostgreSQL
- REST API

## Cách chạy project

### 1. Clone project
git clone https://github.com/HuuToan0410/Do_An_Tot_Nghiep_2026.git

### 2. Tạo virtual environment
python -m venv venv

### 3. Cài dependencies
pip install -r requirements.txt

### 4. Chạy server
python manage.py runserver
